## Description
This web development project was built in collaboration with Olhar de Bia, a social organization committed to eradicating poverty through education. The platform aims to bridge the gap between volunteers and Non-Governmental Organizations (NGOs) by centralizing volunteer opportunities and using AI to match them with suitable candidates.

Key features include:

- Organization & Event Management: Tools for NGOs to register, publish, and manage events.
- Volunteer Profiles: Registration, interest-based profiles, and engagement tracking.
- Personalized Recommendations: Smart matching and filtering to connect volunteers with meaningful opportunities.
